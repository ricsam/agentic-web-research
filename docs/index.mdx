`agentic-web-research` gives your agents fresh web evidence through one authenticated API. It searches with SearXNG, renders selected pages with Playwright, extracts readable Markdown, and asks an OpenAI-compatible model to return a cited answer.

## How it works

<Steps>
  <Step title="Search the web">
    The service sends the research query to your SearXNG deployment and streams each candidate result.
  </Step>
  <Step title="Inspect useful pages">
    The model chooses pages to render. Playwright loads them, readability extraction converts them to Markdown, and private-network access is blocked by default.
  </Step>
  <Step title="Return a cited answer">
    The model submits an answer and source list while the API streams progress, answer deltas, sources, and a final event over Server-Sent Events.
  </Step>
</Steps>

## What you run

| Component | Purpose |
| --- | --- |
| API server | Authenticates requests, runs research tasks, and streams SSE events |
| SearXNG | Supplies web search results |
| Playwright | Renders JavaScript-heavy pages |
| PostgreSQL | Stores settings, API keys, tasks, events, and logs |
| OpenAI-compatible provider | Selects sources and produces the final answer |
| Admin console | Manages providers, research limits, API keys, health, and activity |

<Note>
  Model credentials are configured in the admin console rather than environment variables. The service encrypts a provider's API-key field at rest using `APP_SECRET` and redacts secret-looking custom headers in admin responses.
</Note>
