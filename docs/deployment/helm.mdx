---
title: "Helm"
description: "Deploy agentic-web-research to Kubernetes"
---

The Helm chart can deploy the application with PostgreSQL and SearXNG, or connect to external instances. Chart `0.2.2` and its stock container image are public.

## Install from the public chart repository

Add the GitHub Pages chart repository and create the namespace:

```bash
helm repo add agentic-web-research https://ricsam.github.io/agentic-web-research
helm repo update

kubectl create namespace agentic-web-research \
  --dry-run=client -o yaml | kubectl apply -f -
```

Create the Secret referenced by the chart's `existingSecret` value:

```bash
kubectl create secret generic agentic-web-research-secrets \
  --namespace agentic-web-research \
  --from-literal=APP_SECRET='<long-random-value>' \
  --from-literal=ADMIN_PASSWORD='<admin-password>' \
  --from-literal=POSTGRES_PASSWORD='<database-password>' \
  --from-literal=SEARXNG_SECRET='<long-random-value>'
```

Install the chart:

```bash
helm upgrade --install awr agentic-web-research/agentic-web-research \
  --version 0.2.2 \
  --namespace agentic-web-research \
  --set existingSecret=agentic-web-research-secrets \
  --set env.publicBaseUrl=https://research.example.com \
  --set env.adminEmail=admin@example.com
```

The default image is `ghcr.io/ricsam/agentic-web-research:f7d1fd2a184ba2610b1673d808f232dfdc368adf`. It is public, so the stock installation does not need registry authentication or `imagePullSecrets`.

The public OCI mirror provides the same chart:

```bash
helm upgrade --install awr \
  oci://ghcr.io/ricsam/charts/agentic-web-research \
  --version 0.2.2 \
  --namespace agentic-web-research \
  --set existingSecret=agentic-web-research-secrets
```

<Warning>
  Do not pass credentials with `--set`. Store them in the Secret referenced by `existingSecret`. For production, use your organization's secret-management workflow.
</Warning>

For unattended setup, you can also add `BOOTSTRAP_API_KEY`, `BOOTSTRAP_LLM_API_KEY`, and `BOOTSTRAP_LLM_HEADERS_JSON` to the same Secret. Configure the related non-secret provider values under `bootstrapLlm`.

## Configure ingress

Create a values file:

```yaml
existingSecret: agentic-web-research-secrets

env:
  publicBaseUrl: https://research.example.com
  adminEmail: admin@example.com

ingress:
  enabled: true
  className: traefik
  hosts:
    - host: research.example.com
      paths:
        - path: /
          pathType: Prefix
```

Install it:

```bash
helm upgrade --install awr agentic-web-research/agentic-web-research \
  --version 0.2.2 \
  --namespace agentic-web-research \
  --values values.production.yaml
```

Private image overrides remain supported. Set `image.repository` and `image.tag` or `image.digest`, and add `imagePullSecrets` only when your registry requires authentication.

## Persistence

Bundled PostgreSQL is enabled by default and requests a 10 GiB volume.

```yaml
postgres:
  enabled: true
  storageSize: 10Gi
  storageClassName: rook-ceph-block
```

Set `postgres.storageClassName` to a `ReadWriteOnce` storage class available in your cluster.

## External PostgreSQL

Add `DATABASE_URL` to the Secret named by `existingSecret`, then enable the external database path:

```yaml
postgres:
  enabled: false
  # A non-empty value makes the chart read DATABASE_URL from existingSecret.
  externalDatabaseUrl: from-existing-secret
```

You can change the Secret key name with `secretKeys.databaseUrl`. Do not put the connection string in your values file.

## External SearXNG

```yaml
searxng:
  enabled: false
  externalUrl: https://search.example.com
```

The SearXNG endpoint must allow JSON responses from `/search?format=json`.

## Demo limits

```yaml
demo:
  enabled: false
  rateLimitWindowMs: 600000
  rateLimitMax: 5
  maxConcurrency: 2
  maxDepth: 2
  maxPages: 4
  pageTimeoutMs: 15000
  timeoutMs: 120000
```

Disable the public demo unless you intend to offer unauthenticated research from your deployment.

## Verify

```bash
kubectl rollout status deployment/agentic-web-research \
  --namespace agentic-web-research

kubectl get pods,services,ingress \
  --namespace agentic-web-research
```

Then check the public health endpoint:

```bash
curl https://research.example.com/healthz
```

After deployment, sign in at `/admin`, configure a model provider, and create a research API key.
