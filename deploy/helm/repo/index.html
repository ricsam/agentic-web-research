agentic-web-research Helm charts

Public Helm repository for the self-hosted web research API. No registry login is required to download charts or the default container image.

helm repo add agentic-web-research https://ricsam.github.io/agentic-web-research
helm repo update
helm search repo agentic-web-research --versions

Create the application's credential Secret before installing. Follow the Helm deployment guide for configuration and installation.
